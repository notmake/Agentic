🤖 SWE-bench Coding Agent 的公开案例
1. 用 Claude Code 作为 Coding Agent 跑 SWE-bench 基准
这是一个开源项目，直接使用 Claude Code（claude CLI） 作为 Coding Agent，针对真实的 GitHub Issue 自动生成补丁。它的工作流程很典型：

加载一个 SWE-bench 实例，并克隆仓库到对应的 base_commit；

以无头模式（headless） 运行 Claude Code，仅将 Issue 的问题描述作为上下文；

捕获产生的 git diff 作为预测补丁；

用 SWE-bench 的 Docker 评测框架判定问题是否被解决。

这个案例完整展示了“读取 Issue → 编辑代码 → 产出补丁 → 自动评测”的闭环，是 Coding Agent 解决真实 GitHub Issue 的典型公开实现。

2. 阿里云官方教程：在云沙箱上跑通 SWE Agent 修复缺陷
阿里云的一篇技术文档以一道真实的 SWE-bench 题目为例，演示了如何在云沙箱上跑通 SWE Agent 的完整流程：修复缺陷、产出补丁、并判定是否修好。文中还说明了如何将这套流程批量扩展到自有仓库，接入私有评测集。

3. 量化模型在 SWE-bench Verified 上的表现数据
一些公开报告给出了具体分数，可以作为“能解决实际问题”的量化佐证：

Qwen3.5-35B-A3B 经过纯强化学习训练后，在 SWE-bench Verified 上的解决率从 47.8% 提升至 61.6%（训练样本约 1,800 个）。

另一个基于 Qwen3-30A3B-Instruct 训练的模型，在 SWE-bench-Verified 上达到了 64% 的解决率。
